# Miscellaneous

- Write readable code using the committed Prettier configuration (two spaces, single quotes, semicolons, trailing commas, 100-character target width).
- Run `npm run format` after editing and `npm run check` before finishing. Formatting cannot replace readable names and clear structure.
- Define static game UI markup in native HTML templates in `index.html`. Clone templates for screens and repeated components; use JavaScript for data, events, and lifecycle, and `textContent` for dynamic text. Mount/unmount screens with editor and timer cleanup; use `hidden` for temporary controls.
- When committing, add yourself to commit message
- NEVER push
