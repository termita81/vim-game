Manual probes

  • Try hjkl, ciw, ci", dap, Ctrl-v then I, qa…q@a, ., and :%s/a/b/g.
  • :ping reports a message. Replay demo inserts a sentence using Vim.handleKey.
  • "fp pastes the dead drop. Try native :reg f; the inspect button reads the same register without replacing that command.
  • Set ma, move to an earlier line, insert above, then 'a. Swap away and back, then repeat. Test mA in alpha and 'A in beta.
  • :set rnu / :set nornu toggle the custom gutter. The full relativenumber spelling also works.
  • Show a second view, edit either, then try u in each. Hide it before swapping buffers.
  • :sp / :vsp show a second view; :q, :q!, :e, :e!, :w report interception only. No game flow exists yet.
